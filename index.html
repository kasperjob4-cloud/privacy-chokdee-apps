นโยบายความเป็นส่วนตัว

แอปพลิเคชัน: ChokDee v.2  ·  มีผลตั้งแต่: 2026/09/22

1. ภาพรวม

ChokDee v.2 ("แอปพลิเคชันนี้") เป็นเครื่องมือที่ช่วยให้ผู้ใช้เชื่อมต่อและจัดการการทำงาน กับ Facebook และบริการของ Meta ผ่าน Meta Platform และ Graph API นโยบายฉบับนี้อธิบายว่าแอปพลิเคชันเข้าถึงข้อมูลใดบ้าง นำข้อมูลไปใช้อย่างไร และผู้ใช้สามารถควบคุมหรือเพิกถอนสิทธิ์ได้อย่างไร

แอปพลิเคชันจะเข้าถึงเฉพาะข้อมูลและสิทธิ์ที่ผู้ใช้อนุญาตผ่านระบบของ Facebook/Meta และจะใช้ข้อมูลเพื่อดำเนินการตามคำสั่งของผู้ใช้เท่านั้น

2. ข้อมูลที่เข้าถึง

เมื่อผู้ใช้เข้าสู่ระบบหรือเชื่อมต่อบัญชี Facebook กับแอปพลิเคชัน ผ่าน Facebook Login หรือ Meta OAuth แอปพลิเคชันอาจเข้าถึงข้อมูลต่อไปนี้ ตามสิทธิ์ที่ผู้ใช้อนุญาตและตามสิทธิ์ที่ Meta อนุมัติให้กับแอปพลิเคชัน

  • ข้อมูลบัญชี Facebook — เช่น ชื่อและรหัสประจำตัวของบัญชี เพื่อยืนยันตัวตนและเชื่อมโยงบัญชีกับแอปพลิเคชัน
  • ข้อมูลเพจ Facebook — เช่น ชื่อเพจและรหัสประจำตัวของเพจ หากผู้ใช้อนุญาตให้แอปพลิเคชันทำงานกับเพจดังกล่าว
  • สิทธิ์การจัดการเพจ — ใช้สำหรับดำเนินการที่ผู้ใช้ร้องขอ เช่น การเผยแพร่หรือจัดการเนื้อหาบนเพจ ตามสิทธิ์ที่ได้รับอนุญาต

แอปพลิเคชันจะไม่ขอหรือเข้าถึงข้อมูล Facebook ที่ไม่จำเป็นต่อการทำงาน และจะไม่เข้าถึงข้อมูลส่วนตัวอื่น ๆ ของผู้ใช้เกินกว่าสิทธิ์ที่ผู้ใช้อนุญาต

3. การจัดเก็บข้อมูล

  • ข้อมูลการเข้าสู่ระบบหรือ Access Token จะถูกจัดเก็บอย่างปลอดภัย เพื่อให้แอปพลิเคชันสามารถดำเนินการตามคำสั่งของผู้ใช้
  • แอปพลิเคชันจะไม่ขาย เช่า หรือแลกเปลี่ยนข้อมูลผู้ใช้กับบุคคลที่สาม
  • แอปพลิเคชันจะไม่ใช้ข้อมูล Facebook เพื่อการโฆษณาหรือการตลาด นอกเหนือจากวัตถุประสงค์ที่ระบุไว้ในนโยบายนี้
  • ข้อมูลจะถูกเก็บไว้เท่าที่จำเป็นต่อการให้บริการและการทำงานของแอปพลิเคชัน

4. การใช้ข้อมูล

ข้อมูลที่ได้รับจาก Facebook/Meta จะถูกใช้เฉพาะเพื่อให้บริการที่ผู้ใช้ร้องขอ เช่น การยืนยันบัญชี การเชื่อมต่อ Facebook Page การอ่านข้อมูลที่จำเป็น หรือการเผยแพร่และจัดการเนื้อหาบนเพจตามคำสั่งของผู้ใช้

แอปพลิเคชันจะไม่ใช้ข้อมูล Facebook เพื่อวัตถุประสงค์อื่น ที่ไม่เกี่ยวข้องกับการให้บริการโดยไม่ได้รับอนุญาตจากผู้ใช้

5. การแชร์ข้อมูลกับบุคคลที่สาม

แอปพลิเคชันจะไม่ขายหรือให้เช่าข้อมูลส่วนบุคคลของผู้ใช้แก่บุคคลที่สาม และจะไม่เปิดเผยข้อมูล Facebook เว้นแต่จำเป็นต่อการให้บริการ เพื่อปฏิบัติตามกฎหมาย หรือได้รับความยินยอมจากผู้ใช้

ข้อมูลที่ได้รับจาก Facebook/Meta จะไม่ถูกนำไปใช้เพื่อสร้างฐานข้อมูล สำหรับการขายหรือการตลาดของบุคคลที่สาม

6. การเพิกถอนสิทธิ์

ผู้ใช้สามารถยกเลิกการเชื่อมต่อแอปพลิเคชันกับบัญชี Facebook ได้ตลอดเวลา ผ่านการตั้งค่าของบัญชี Facebook

  • Facebook — Apps and Websites
  • ผู้ใช้สามารถลบหรือยกเลิกการเชื่อมต่อแอปพลิเคชัน จากบัญชี Facebook ของตนเอง

เมื่อผู้ใช้เพิกถอนสิทธิ์แล้ว แอปพลิเคชันจะไม่สามารถใช้ Access Token เพื่อเข้าถึงข้อมูล Facebook ที่ได้รับอนุญาตก่อนหน้านี้ได้อีก

7. การลบข้อมูล

ผู้ใช้สามารถร้องขอให้ลบข้อมูลที่เกี่ยวข้องกับบัญชี Facebook ที่แอปพลิเคชันจัดเก็บไว้ได้ โดยติดต่อเราตามข้อมูลในส่วน "ติดต่อ"

เมื่อได้รับคำขอ แอปพลิเคชันจะดำเนินการตรวจสอบและลบข้อมูลที่เกี่ยวข้อง ตามขอบเขตและระยะเวลาที่เหมาะสม เว้นแต่มีข้อกำหนดทางกฎหมาย ที่จำเป็นต้องเก็บรักษาข้อมูลดังกล่าว

8. ความปลอดภัย

เราใช้มาตรการที่เหมาะสมเพื่อป้องกันข้อมูลผู้ใช้จากการเข้าถึง การแก้ไข การเปิดเผย หรือการทำลายโดยไม่ได้รับอนุญาต

Access Token และข้อมูลการเชื่อมต่อจะถูกจำกัดการเข้าถึง เฉพาะส่วนของระบบที่จำเป็นต่อการทำงานของแอปพลิเคชัน และไม่ควรถูกเผยแพร่ในระบบควบคุมเวอร์ชันหรือพื้นที่สาธารณะ
